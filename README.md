# Построение прототипа книжного рекомендательного сервиса

Реализованы **Popularity, Content-based TF-IDF, Item-based CF и SVD**, анализ данных, визуализации, RMSE и сравнение Precision@5 / Recall@5 / nDCG@5.

## Для запуска

1. Установить Python 3.10+ и Jupyter Notebook (или открыть ноутбук в Google Colab).
2. Установить зависимости:

   ```bash
   pip install pandas numpy matplotlib scipy scikit-learn jupyter
   ```
3. Положить рядом с `book_recommendations.ipynb` файлы `ratings.csv`, `books.csv`, `tags.csv`, `book_tags.csv` из [Goodbooks-10k](https://www.kaggle.com/datasets/zygmunt/goodbooks-10k).
4. Открыть ноутбук и выполнить все ячейки сверху вниз.


## Структура

- `book_recommendations.ipynb` - весь код, графики и выводы.
- `ratings.csv` - выставленные оценки.
- `books.csv` - сведения о книгах.
- `tags.csv`, `book_tags.csv` - теги.

## Методы

- **Popularity** - средний рейтинг по обучающим данным с минимальным порогом в 50 оценок.
- **Content** - TF-IDF для названий и тегов, косинусное сходство.
- **Item-based CF** - сходство книг по пользовательским оценкам, разреженная матрица `csr_matrix`.
- **SVD** - TruncatedSVD на матрице оценок с центрированием по пользователям.

## Оценка

Оценки разбиваются на train/test отдельно для каждого пользователя (примерно 80/20 для пользователей с 5+ оценками). Положительная оценка - 4 или 5 Для 200 случайных подходящих пользователей строятся кандидаты из тестовых книг плюс 100 непрочитанных книг. 
Все модели оцениваются по одному и тому же набору кандидатов. Это *sampled evaluation*; метрики не следует интерпретировать как качество на полном каталоге. SVD дополнительно проверяется через RMSE на отложенных оценках.

Ключевая особенность данных: `ratings.csv` содержит приблизительно до 100 оценок на книгу, поэтому для визуализации длинного хвоста используется `books.ratings_count` , но в обучение и ранжирование эта глобальная колонка не попадает.
